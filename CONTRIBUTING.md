# Contributing

This is a generated publication repository and does not accept direct content changes.

Fatti maintainers must:

1. update the controlling internal document in the private master;
2. update the public source under `client-pack/public-repo/` in that master;
3. complete technical, privacy and release review as applicable;
4. run the private repository's documentation checks;
5. use the `Publish trust centre` workflow to open a generated pull request here; and
6. merge only after the required public-repository checks and review pass.

For an external correction request, open an issue without confidential information or contact Fatti through the existing client/support channel. Do not publish security findings, credentials, personal information or client data in an issue.
