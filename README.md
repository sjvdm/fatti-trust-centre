# Fatti Trust Centre

This repository publishes Fatti's public security, privacy, architecture and resilience documentation through GitHub Pages.

> **Generated repository — do not edit content here.** The private `fatti-security-compliance` repository is the master. Approved changes are copied here by its `Publish trust centre` workflow, submitted as a pull request and merged through the protected `main` branch.

Public site: [https://sjvdm.github.io/fatti-trust-centre/](https://sjvdm.github.io/fatti-trust-centre/)

The public content is deliberately high level. It does not contain internal controls, gaps, evidence, detailed topology, source documents, questionnaires or confidential client information.

## Repository controls

- `main` accepts changes only through pull requests.
- The public-content validation check must pass before merge.
- A code-owner review is requested for all changes.
- GitHub Pages deploys only after a change reaches `main`.

If a correction is needed, make it in the private master and republish. Public-repository pull requests that do not originate from the controlled publication process should be closed and recreated from the master.
