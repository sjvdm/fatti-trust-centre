# Security

Fatti applies security measures according to the services and infrastructure it manages. Client environments differ, so control coverage is confirmed for the applicable deployment rather than presented as a universal configuration.

<div class="principles">
  <div><h3>Network boundaries</h3><p>Managed deployments use network security controls and protected administrative connectivity. Site firewalling, segmentation and remote access depend on the agreed design.</p></div>
  <div><h3>Access control</h3><p>Administrative access is limited to authorised roles. Fatti is consolidating access paths and periodic reviews so that assurance can be tied to current evidence.</p></div>
  <div><h3>Monitoring and support</h3><p>Managed network services can include central monitoring, alert handling and support. The exact hours, event coverage and escalation path are contractual.</p></div>
  <div><h3>Change and vulnerability handling</h3><p>Software and infrastructure changes follow controlled release and maintenance processes. Priorities and remediation commitments are assessed against service risk and scope.</p></div>
</div>

## Assurance

Fatti maintains internal architecture, policy, control, risk and evidence records to support client reviews. Detailed configurations, findings and evidence may be shared selectively where appropriate and subject to confidentiality.

This public trust centre does not claim that every data path is encrypted in the same way, that multi-factor authentication covers every possible access path, or that Fatti holds a certification that is not listed here. Those questions are answered against current, service-specific evidence.

## Reporting a concern

Please report a suspected security issue through your Fatti account or support contact, with the affected service and enough detail for safe triage. Do not include passwords, access tokens or unnecessary personal information.
